> ### АНТИВИРУСНОЕ ПО
> WinDivert способен вызвать срабатывание антивируса.  
> Это средство перехвата и фильтрации сетевого трафика, необходимое для работы zapret.
> WinDivert может применяться как легитимными, так и вредоносными программами, однако сам по себе вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует файлы WinDivert как инструменты повышенного риска или хакерские утилиты. В результате файл удаляется и помещается в карантин. Название обнаружения при этом обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог с zapret в исключения антивируса либо выключите обнаружение PUA — потенциально нежелательных приложений. Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы точно понимаете настройку исключений, предпочтительнее добавить исключение; если нет — рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Активируйте безопасный DNS (Secure DNS).
    * В Chrome включите "Использовать безопасный DNS" и укажите поставщика, отличного от "Поставщик по умолчанию".
    * В Firefox откройте настройку "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS непосредственно в параметрах системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 рекомендуется этот вариант.
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, при настройке и использовании Secure DNS на компьютере могут возникнуть проблемы.

2. Скачайте zip- или rar-архив с [последнего релиза](https://github.com/portalchemistagitate/zapret-discord-youtube/releases/latest).

3. Откройте свойства загруженного архива и установите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот шаг не требуется.

4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов.

5. Запустите нужный сценарий:
    * Для поиска работающей стратегии: **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`.
    * Для установки стратегии в автозапуск: **`service.bat`** → `Install Service` → *выберите подходящую стратегию*.

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества факторов, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вас**.

- [**`service.bat`**](./service.bat) — установка автозапуска и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск служб (services.msc)</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб
  - **`Check Status`** — посмотреть состояние обхода и служб, включая стратегию в автозапуске и WinDivert
  - **`Game Filter`** — включить или выключить режим обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию нужно перезапустить.**  
  В скобках отображается текущее состояние — включено или выключено.
  - **`IPSet Filter`** — изменить режим обхода ресурсов из `ipset-all.txt`.  
  Опция полезна при поиске причины, если ресурс не открывается с zapret, хотя без него работает.  
  В скобках показывается текущий режим:
    - `none` — ни один IP не проверяется
    - `loaded` — проверяются IP, входящие в список
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включить или отключить автоматический поиск обновлений
  - **`Replace active fakes`** — заменить выбранный активный fake на другой из каталога `bin`
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовым чатам Discord**</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений
  - **`Run Diagnostics`** — проверить распространённые причины неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работу приложения после внезапного сбоя.
  - **`Run Tests`** — открыть инструмент проверки стратегий:
    - `Standard tests` — проверить сайты из `utils/targets.txt`
    - `DPI checkers` — проверить DPI у разных провайдеров, включая Cloudflare, Amazon и другие


## ☑️Распространенные вопросы и проблемы

### После запуска `general*` ничего не произошло

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, который можно увидеть на панели задач.  
Если winws.exe не запустился, обратитесь к [#522](https://github.com/portalchemistagitate/zapret-discord-youtube/issues/522).

### Не удалось подобрать стратегию
- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts окажется устаревшим, скрипт предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося Блокнота.
  - Откройте файл `hosts` в созданной папке с помощью текстового редактора, запущенного от имени администратора.
  - Вставьте скопированное в конец файла `hosts` или замените ранее добавленные аналогичные строки.
  - Сохраните файл и снова проверьте подключение. Если результат не изменился, убедитесь, что hosts действительно был сохранён.

#### Работа не гарантируется. Если способ не помог, установите [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) и подключите [локальный прокси](https://github.com/portalchemistagitate/tg-ws-proxy) либо любой публичный прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Стратегии не обязательно работают постоянно.**
> Обнаружение используемого метода может привести к тому, что ранее рабочая стратегия со временем перестанет помогать.
> В этом репозитории есть много вариантов обхода. Если ни один не подходит, создайте собственную стратегию на основе одной из представленных и измените её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте результат `service.bat` → `Run Diagnostics` и устраните найденные ошибки.

- Убедитесь, что нужный адрес включён в списки доменов или IP.

- Проверьте другие варианты, в том числе **`ALT`**, **`FAKE`** и прочие стратегии.

- Выполните полную переустановку по инструкции ниже.

- Дополнительная информация: [#765](https://github.com/portalchemistagitate/zapret-discord-youtube/issues/765).

### Как полностью переустановить или обновить сборку?
- Сохраните добавленные вами ресурсы и другие нужные данные.
- Перезапустите устройство.
- Откройте `service.bat` → `Remove Services`.
- Затем выберите `service.bat` → `Run Diagnostics`; если будут обнаружены ошибки, исправьте их и в конце ответьте `Y`.
- Удалите каталог zapret.
- Загрузите свежую версию со [страницы релизов](https://github.com/portalchemistagitate/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа есть пункт разблокировки, установите его, нажмите "Применить", затем "ОК".
- Распакуйте архив в новый каталог в корне диска; путь не должен содержать пробелы и специальные символы.
- Запускайте разные скрипты `general`, проверяя доступ к интернет-ресурсам. Если выбранный вариант не работает, закройте программу через значок замочка на панели задач и попробуйте другую стратегию.
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` → `Install Service` → выберите нужный вариант.

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о проблеме с WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### На Windows 7 требуется цифровая подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в каталоге [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё отображается среди служб

1. Узнайте имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS](#%EF%B8%8Fиспользование) настроен.
- Отключите блокировщик рекламы: известно, что YouTube начал активно с ними бороться.
- Переберите остальные стратегии, особенно если раньше всё работало.
- См. также [#251](https://github.com/portalchemistagitate/zapret-discord-youtube/discussions/251).

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) включён.
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её.
- В `service.bat` откройте `Run Diagnostics` и выполните очистку кэша Discord.
- Проверьте работу приложения Discord после очистки кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей.
- Если браузерная версия тоже недоступна, повторно проверьте все стратегии. YouTube и Discord могут работать на разных вариантах.
- Дополнительные сведения: [#252](https://github.com/portalchemistagitate/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/portalchemistagitate/tg-ws-proxy).
- Либо подключите бесплатный MTProto-прокси из интернета.

### Не работают игры

Игр много, поэтому проверить и исправить работу каждой из них невозможно.

Попробуйте универсальную последовательность:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

Имейте в виду: при `ipset any` многие сайты могут перестать открываться. Не оставляйте этот режим включённым постоянно. Лучше определить все IP-адреса, которые использует игра, и внести их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/portalchemistagitate/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет моей проблемы

- Создайте описание проблемы [здесь](https://github.com/portalchemistagitate/zapret-discord-youtube/issues).

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода можно указать в следующих файлах:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены, которые нужно исключить, например когда IP-сеть уже есть в `ipset-all.txt`, но конкретный домен из неё фильтровать не требуется
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые необходимо исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
